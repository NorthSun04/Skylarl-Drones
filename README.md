# Skylark Drones - BI Agent

This repository contains data assets and analysis code for the Skylark Drones Business Intelligence (BI) agent.

## 📁 Repository Structure

* `skylark-bi-agent/` - Source code and scripts for the BI agent logic.
* `deal_funnel.csv` - Dataset containing sales pipeline, lead, and deal funnel metrics.
* `work_orders.csv` - Dataset containing work order details, status, and operational tracking.
* `skylark-bi-agent-submission.zip` - Compressed project submission package.
